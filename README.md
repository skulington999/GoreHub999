# VIDEO ARCHIVE — GitHub Pages

Site statique façon YouTube avec **10 vidéos exactement**.

### Personnalisation
- `assets/logo.png` → remplace par ton PNG.
- `assets/background.jpg` → remplace par ton fond.
- `assets/thumbnails/01.jpg` à `10.jpg` → remplace par tes miniatures.
- `videos.js` → change les titres, liens vidéo, durées, vues et dates.

### GitHub Pages
Repository → **Settings → Pages → Deploy from a branch → main → / (root)**.

Le site ne contient aucun framework ni installation : tu peux déposer directement ces fichiers dans GitHub.
